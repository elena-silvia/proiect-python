#MP3-Player
A desktop application for audio playback and library management with a multi-user authentication system.

### Tech Stack:
  * **Python** - main application logic;
  * **CustomTkinter** - for building a modern GUI;
  * **SQLite3** - for efficiently organizing and saving songs and playlists;

### Main Features:
* **Loading** and playing local audio files;
*Volume control and playback management (Play/Pause/Next/Back);
*Song Queue System - a queue manager that allows users to add upcoming tracks and view or modify the playing order;
*Playlist & Library Management - users can create, view or delete custom playlists; songs are stored in a library linked via a relational database layout;
*Duplicate prevention - a song cannot be added multiple times to the same playlist
